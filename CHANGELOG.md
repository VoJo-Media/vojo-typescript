# Changelog

This project follows [Semantic Versioning](https://semver.org). Until 1.0, a minor version can include breaking changes.

## 0.1.0 (2026-11-19)

First version, generated from API version `2026-10-07`.

- A client for every API operation, with types for every request and response
- Auto-paging lists, with protection against repeating cursors
- Typed errors for each kind of failure
- Automatic retries and idempotency keys
- Webhook signature verification and typed events
